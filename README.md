# Arief — Operations Portfolio

Personal portfolio of **Arief Hidayatullah (ariefmorfhi)**, Operations Supervisor at Boulder Planet Indonesia.

- Bilingual: English / Bahasa Indonesia (toggle in the top bar, or open with `#en` / `#id` at the end of the link)
- Light and dark mode follow the visitor's device setting
- Plain HTML, CSS and JavaScript — no build step

## Publish with GitHub Pages
1. Create a repository (e.g. `ariefmorfhi.github.io` for a root site, or any name for a project site).
2. Upload everything in this folder (`index.html`, `certs/`, `journey/`, `morfhi.webp`).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. Your site appears at `https://<username>.github.io/` (or `https://<username>.github.io/<repo>/`).
